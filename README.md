# Act4. API REST con Spring Boot, Spring Security y JWT

Proyecto API REST con funciones para la manipulacion de una base de datos solo con el uso de los endpoints para crear empleads

## Funcionamiento
El proyecto implementa endpoints para acciones crud para manipular una base de datos sin vista (frontend), el proyecto tambien implementa la libreria de spring security para que las funciones funcionen siempre y cuando se haya proporcionado el token que se obtiene al momento de logearse por json

### Despliegue
El proyecto se encuentra desplegado y funcionando correctamente en este [link](https://veterinariabobby.tech/eaecact4_t4/) .
